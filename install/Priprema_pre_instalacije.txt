AGRIX - PRIPREMA PRE INSTALACIJE

Pre lokalne instalacije pripremi Google, banku i (opciono) SEF podatke.

1. GOOGLE - JEDAN NALOG, FOLDERI I GAS PO KLIJENTU

Svi klijenti su na ISTOM Google nalogu: ops@agrix.rs.
Unutar tog naloga, PO KLIJENTU napravi:
- poseban root folder na Drive-u: AgriX_C00X_PROD
  (celu strukturu pravi bootstrapAgriXFolderTree; vidi onboarding vodic
   install/AgriX_Onboarding_Vodic_Novi_Klijent_v2.md, sekcije 5/8/11)
- poseban Apps Script projekat: AgriX_C00X_GAS_PROD (Web App /exec)

Stammdaten nastaje u 01_Sheets/02_Master -> GOOGLE_PWA_FOLDER_ID je ID
foldera 02_Master (NE ceo 01_Sheets).

2. GOOGLE OAUTH

U Google Cloud Console (nalog ops@agrix.rs) pripremi OAuth credentials,
tip: Desktop app. Ako je app u test modu, dodaj nalog kao test user.

Vrednosti idu u AgriX tblSEFConfig (NE tblConfig -- kod cita GOOGLE_* iz
tblSEFConfig):

ConfigKey             ConfigValue
GOOGLE_CLIENT_ID      <client id>
GOOGLE_CLIENT_SECRET  <client secret>
GOOGLE_PWA_FOLDER_ID  <ID foldera 01_Sheets/02_Master>
MONITORING_ENDPOINT   <GAS Web App /exec URL>
MONITORING_SECRET     <MONITORING_INGEST_SECRET>
CLOUD_SYNC_ENABLED    YES

3. BANKA - POSEBAN NALOG PO KLIJENTU + DOWNLOADER GAS

Za banku napravi POSEBAN Google nalog PO KLIJENTU (na njega banka salje
izvode). Na tom nalogu instaliraj Bank PDF Downloader GAS
(gas/bank-pdf-downloader/) koji PDF izvode spusta u Drive folder
00_Inbox/01_Bank (koji zivi u stablu klijenta AgriX_C00X_PROD).

Povezivanje (isti folder ID od 01_Bank na tri mesta):
- podeli folder 01_Bank tom bankarskom nalogu kao Editor
- taj isti folder ID upisi u BANK_IMPORT_CLIENTS_JSON.driveFolderId (GAS)
- na masini sa Excelom: Google Drive for Desktop -> Add shortcut to Drive
  za 01_Bank (da bi ga VBA video lokalno); 00_Inbox -> Available offline
- lokalnu putanju do 01_Bank upisi u BANKA_DRIVE_SOURCE_PATH (tblLocalConfig)

4. SEF API KEY (opciono, samo ako se koristi e-faktura)

Uloguj se u SEF/eFaktura kao ovlasceni korisnik firme, pa u API pristupu
generisi/kopiraj API kljuc. U AgriX tblSEFConfig:

ConfigKey       ConfigValue
SEF_BASE_URL    <SEF endpoint>
SEF_API_KEY     <API kljuc>
SEF_ENV         PROD ili TEST/DEMO

API kljuc je tajna vrednost - ne slati javno niti commitovati u GitHub.
