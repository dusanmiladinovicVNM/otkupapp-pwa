# Mapa sposobnosti -- oblast C: IZVESTAJI, SLEDLJIVOST, PALETE

Moduli: `modScrIzvestaji` + `modIzvestaj`, `modScrSledljivost` + `modSledljivost`,
`modScrPalete` + `modPaletniList`, i `modPrint` u delu koji ovi ekrani pokrecu.
Podoblasti: C1 ekran IZVESTAJI (liste, snimci, detalji, stampa) - C2 ekran
SLEDLJIVOST (liste, rucno i auto povezivanje, GlobalGAP stampa) - C3 ekran
PALETE (palete, paletni/preradni list) - C4 stampa dokumenata pokrenuta iz ovih
ekrana.

**A-018/A-019**; storno tokovi su **oblast B**. Ovde se na njih samo upucuje.
